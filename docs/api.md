# ملخص الـ APIs والصلاحيات

البادئة: `/api`. الوثيقة الكاملة: [openapi.json](openapi.json) أو `http://localhost:4000/api/docs` أثناء التشغيل.

- المصادقة: Cookie `lp_session` (HttpOnly).
- كل طلب معدِّل يتطلب الترويسة `x-csrf-token` بقيمة Cookie `lp_csrf`، ويُرفض إن حمل Origin غير `WEB_ORIGIN`.
- الأخطاء: `{ statusCode, code, message, fields?, details? }`.

| الطريقة والمسار                                           | الوصف                                                                                                                       | الصلاحية           |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `GET /health`                                             | حالة التطبيق وقاعدة البيانات (200 أو 503)                                                                                   | عام                |

مدير النظام يملك كل الصلاحيات دائمًا. حسابه لا يُعدَّل عبر `/users/*` (403 `ADMIN_ACCOUNT_PROTECTED`).

## حفظ المسودة `PUT /forms/:id/draft` (المرحلة الثانية)

- الجسم يمثل **القائمة الكاملة المرتبة**: ترتيب العناصر هو الترتيب المحفوظ، والأسئلة أو الخيارات الغائبة تُحذف.
- السؤال أو الخيار الموجود يُرسل بـ `id` الذي أعاده الخادم، والجديد يُرسل دون `id` فيُنشئ الخادم له معرّفًا ثابتًا.
- كل `id` مرسل يجب أن يخص هذه المسودة، وكل `id` خيار يجب أن يخص السؤال نفسه؛ غير ذلك ⇒ 400 مع `questions.N.id` أو `questions.N.options.M.id`.
- الترتيب داخل المعاملة: قفل صف النموذج ⇒ رفض المؤرشف (409 `FORM_ARCHIVED`) ⇒ مطابقة `revision` (409 `REVISION_CONFLICT` ومعه `details.current` المسودة الكاملة الأحدث) ⇒ التحقق من الملكية ⇒ تطبيق الفروق ⇒ زيادة `revision` مرة واحدة إن تغيّر المحتوى. أي فشل يلغي كل شيء.
- الحفظ دون أي تغيير يعيد المسودة نفسها دون زيادة `revision`.
- لا يتغير منشئ النموذج، ويُسجَّل الحفظ في سجل التدقيق بالإجراء `form.draft_saved` (أعداد المضاف والمحذوف والمعدّل، دون محتوى).
- مسار المرحلة الأولى `PATCH /forms/:id` ما زال يعدّل العنوان والوصف فقط، بالقفل نفسه و`revision` نفسه، ولا يلمس الأسئلة.

| النوع `type`      | `settings` (كل الحقول اختيارية ما لم يُذكر)                                                                             | `options`      |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------- |
| `SHORT_TEXT`      | `minLength` 0–500، `maxLength` 1–500                                                                                    | فارغة          |
| `PARAGRAPH`       | `minLength` 0–10000، `maxLength` 1–10000                                                                                | فارغة          |
| `SINGLE_CHOICE`   | `{}`                                                                                                                    | 2–50 دون تكرار |
| `MULTIPLE_CHOICE` | `minSelections`، `maxSelections` من 1 حتى عدد الخيارات                                                                  | 2–50 دون تكرار |
| `DROPDOWN`        | `{}`                                                                                                                    | 2–50 دون تكرار |
| `NUMBER`          | `allowDecimals` (مطلوب)، `min`، `max` بقيمة مطلقة حتى 10¹²؛ أعداد صحيحة إن منعت الكسور                                  | فارغة          |
| `DATE`            | `minDate`، `maxDate` بصيغة `YYYY-MM-DD` بين 1900-01-01 و2100-12-31                                                      | فارغة          |
| `FILE_UPLOAD`     | `allowedTypes` (مطلوب، من: pdf، jpg، png، webp، docx، xlsx، txt)، `maxFileSizeMb` (مطلوب 1–25)، `maxFiles` (مطلوب 1–10) | فارغة          |

يُرفض: الحقول غير المعروفة، والإعدادات التي لا تخص النوع، وعنوان السؤال الفارغ أو المكون من مسافات، والخيارات الفارغة أو المكررة بعد إزالة المسافات (دون تمييز حالة الأحرف)، والحد الأدنى الأكبر من الأقصى، والتواريخ غير الصالحة، والأعداد غير المنتهية أو خارج الحدود، والمعرّفات المكررة أو غير الصالحة. أقصى 100 سؤال. حجم جسم هذا الطلب حد إجمالي مستقل مقداره 4 ميغابايت، يُطبق مع حدود الأحرف لا بدلًا منها: أعلى من الحالات المقاسة بأقصى الحدود (≈ 2.45 ميغابايت بنص عربي و≈ 3.53 ميغابايت بأحرف 3 بايت؛ الحساب في `apps/api/src/forms/questions/limits.ts`)، لكنه لا يدّعي تغطية كل نص تسمح به حدود الأحرف (مثل محارف التحكم المهرّبة في JSON)، وما يتجاوزه ⇒ 413 `PAYLOAD_TOO_LARGE` برسالة عربية دون أي حفظ. بقية المسارات حدها 100KB.

## رموز الأخطاء الشائعة

| code                                                            | الحالة | المعنى                                                                    |
| --------------------------------------------------------------- | ------ | ------------------------------------------------------------------------- |
| `UNAUTHENTICATED`                                               | 401    | لا جلسة، أو جلسة ملغاة/منتهية، أو المستخدم معطّل                          |
| `INVALID_CREDENTIALS`                                           | 401    | بيانات دخول خاطئة أو حساب غير مفعّل                                       |
| `LOGIN_TEMPORARILY_LOCKED`                                      | 429    | إيقاف مؤقت بعد محاولات فاشلة متتالية                                      |
| `TOO_MANY_REQUESTS`                                             | 429    | تجاوز حد طلبات الدخول لعنوان IP                                           |
| `CSRF_INVALID`                                                  | 403    | رمز CSRF مفقود/خاطئ أو Origin غير معتمد                                   |
| `FORBIDDEN`                                                     | 403    | لا يملك الصلاحية المطلوبة                                                 |
| `ADMIN_ACCOUNT_PROTECTED`                                       | 403    | محاولة تعديل حساب مدير النظام من إدارة المستخدمين                         |
| `VALIDATION_FAILED`                                             | 400    | بيانات غير صحيحة، مع `fields[]` برسائل عربية                              |
| `NOT_FOUND`                                                     | 404    | العنصر غير موجود                                                          |
| `USERNAME_TAKEN`                                                | 409    | اسم المستخدم مستخدم                                                       |
| `REVISION_CONFLICT`                                             | 409    | تعديل على مراجعة قديمة؛ `details.current` فيها النسخة الحالية             |
| `FORM_ARCHIVED` / `FORM_ALREADY_ARCHIVED` / `FORM_NOT_ARCHIVED` | 409    | تعارض حالة الأرشفة                                                        |
| `WRITE_CONFLICT`                                                | 409    | تعذر الحفظ بعد إعادة المحاولة بسبب تعارض أقفال متزامن؛ لم يُحفظ شيء       |
| `PAYLOAD_TOO_LARGE`                                             | 413    | جسم الطلب يتجاوز الحد: 4 ميغابايت لحفظ المسودة و100KB لغيره؛ لم يُحفظ شيء |
| `DATABASE_UNAVAILABLE`                                          | 503    | قاعدة البيانات غير متاحة                                                  |
