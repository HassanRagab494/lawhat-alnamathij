# القبول النهائي — لوحة النماذج

التاريخ: 2026-10-14 · البيئة المحلية: Windows 11، Node.js v25.9.0، npm 11.12.1، MySQL 8.4.9 على `127.0.0.1:3306`.

## الخلاصة

**المشروع ليس مغلقًا بالكامل.** الكود والاختبارات المحلية مكتملة وناجحة، لكن التحقق على الاستضافة لم يُنفذ. لم يتوفر لي وصول إلى الخادم أو Coolify: لا مفاتيح SSH ولا رمز Coolify، وDocker غير مثبت محليًا. **لم يُنشر شيء.**

## الأمان والخصوصية في هذه المرحلة

- **لا تبعيات جديدة:** التحقق من الملفات وفك ZIP وعميل ClamAV بوحدات Node المدمجة.
- **الملفات:**
  - خارج المجلد العام وطبقة الحاوية، في volume خاص.
  - المجلد يملكه المستخدم `node` بصلاحية 0700.
  - لا روابط عامة؛ التنزيل محمي ويُسجَّل.
- **الرفض الآمن:**
  - رفض مبكر يستهلك باقي الجسم بحد، لتصل رسالة الخطأ.
  - مهلة وكيل `/api` في Next رُفعت إلى 120 ثانية للرفع والفحص.
- **فحص الأسرار في الفرق قبل الـ commit:** انظر قسم «الرفع».

## القيود والقرارات المفتوحة

1. **النشر على الاستضافة لم يُنفذ:** لا وصول لدي. الخطوات الدقيقة بالترتيب في [`deploy/coolify/README.md`](../../deploy/coolify/README.md#خطوات-النشر-بالترتيب):
   1. نسخة قبل النشر.
   2. حساب النسخ والسران الجديدان.
   3. Redeploy للمورد فقط.
   4. التحقق من الـ migrations والصحة وClamAV والنسخ والاستعادة وXFF والملفات الحقيقية.
2. **موارد الخادم لـ ClamAV غير مقيسة:** تحتاج ≥ 2.5GB ذاكرة حرة. إن لم تتوفر، فالقرار للمالك بين ترقية الخادم أو إبقاء الرفع معطلًا، ولا يُقبل ملف دون فحص.
3. **نسخة خارج الخادم:** تحتاج وجهة يحددها المالك.
4. **التنبيهات الأمنية:** مفتوحة؛ تحتاج قرار ترقية أو قبول.
5. **اختبار «لكل زائر عنوانه»:** يحتاج عميلًا ثانيًا.
6. **حدود المعدل في الذاكرة:** نسخة API واحدة فقط.
7. **خارج النطاق:** الإشعارات، وXLSX، والأسئلة الشرطية، وحذف الردود أو ملفاتها.

- لا قيم من `.env` أو `.env.admin.local`.
- لا كلمات مرور حسابات تجربة المتصفح، ولا مفتاح تشفير نسخ الاختبار.
- لا مسارات أو بريد شخصي، ولا مفاتيح أو رموز.

كلمات `p5.*` في `phase5.e2e-spec.ts` قيم ثابتة لحسابات تُنشأ وتُحذف في قاعدة الاختبار المعزولة. سلسلة EICAR في `test/fixtures/files.ts` هي ملف الاختبار القياسي غير الضار.

**ما لم يُضف إلى Git:** `.env*`، الملفات المرفوعة، النسخ الاحتياطية، القواعد، `node_modules`، ملفات البناء. ملفا البيانات المؤقتان لتجربة النسخ والمتصفح حُذفا قبل الإضافة.

الدمج مع `origin/main` تم دون force، ومطابقة SHA البعيد مسجلة في رسالة التسليم.
